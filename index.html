Apresentação & Conceito

O posicionamento da marca pessoal e os valores estéticos fundamentais do projeto aplicados na web.

PROPÓSITO DIGITAL

A interface do website deve ser entendida como a principal extensão digital da marca. O propósito é transmitir proximidade, elegância e autoridade natural do trabalho da Alice Stoff, sem recorrer a excessos gráficos ou recursos poluídos comuns em sites corporativos.

Posicionamento de Comunicação Web

Alice Stoff fala para um público sofisticado e conectado. A interface digital deve mesclar sensibilidade criativa e credibilidade profissional. A estética segue a linha editorial de alta costura e revistas de design impresso, combinada com colagens e scrapbook orgânico contemporâneo.

DEVE PARECER

  • • Editorial e fluida (como um catálogo impresso)
  • • Orgânica, humana e acolhedora
  • • Minimamente sofisticada
  • • Autoral e criativa

NÃO DEVE PARECER

  • × Fria, engessada ou puramente corporativa
  • × Genérica baseada em templates pré-prontos
  • × Poluída com pop-ups ou efeitos visuais agressivos
  • × Infantil ou colorida de forma artificial

Grid & Ritmo Visual

Regras de layout, uso de espaços e controle de animações para garantir elegância e clareza de leitura.

CONSELHO DE DIREÇÃO EDITORIAL

O ritmo de navegação no site deve ser fluido e natural. Respeite os espaços em branco (respiros editoriais) para dar foco ao conteúdo principal, evitando layouts sobrecarregados de informações ou grids densos demais.

Layout & Navegação

  • Transições Suaves: Use transições invisíveis ou suaves nos links e menus. Evite efeitos de zoom contínuo ou transições 3D agressivas no carregamento de blocos.
  • Atenção Inicial: Garanta que o topo da página (Hero area) prenda a atenção nos primeiros 3 segundos usando o título principal em Cosmodrome Monoline e o texto de apoio em Albert Sans, sem carrosséis frenéticos de banners.

Tabela de Boas Práticas - Motion Design Web & UX

RECOMENDADO (DISCRETO)
  • Efeitos de hover suaves via CSS (mudança sutil de cor ou escala 1.02)
  • Fade-in progressivo de blocos de imagem ao rolar a página
  • Aparecimento suave de menus e modais com controle de opacidade
EVITAR (EXAGERADO)
  • Animações de entrada pesadas (bounce, tremor, rotações 3D)
  • Efeitos visuais de tremor/glitch em botões e links
  • Pop-ups automáticos e elementos que flutuam sem propósito

Componentes & Grafismos (UI)

Aplicação de letterings manuscritos e grifos orgânicos para direcionamento de foco e UX.

PROPÓSITO DOS GRAFISMOS

Nunca utilize intervenções gráficas apenas para decorar. Cada rabisco, seta ou palavra manuscrita deve surgir com o único propósito de ressaltar ações importantes do usuário (como botões e links) ou destacar informações-chave.

Diretrizes de Tipografia Web

  • Mantenha blocos de parágrafos de texto curtos, com boa altura de linha (ex: `line-height: 1.6`) para facilitar a leitura.
  • Destaque termos específicos no texto em Laranja para criar hierarquia visual e direcionamento ocular rápido.
  • Utilize a cor Off White como cor de fundo dominante e para blocos de legenda sutil, evitando contrastes agressivos de branco absoluto.

Grafismos e Detalhes Manuais

  • Setas e círculos apontadores devem ter aparência de desenho feito à mão com pincel fino (use SVGs para melhor nitidez).
  • Sublinhados e grifos manuais acompanham apenas as palavras e links que requerem ação do usuário.
  • Títulos curtos de grande impacto e frases inspiracionais devem usar a fonte cursiva Cosmodrome.

Briefing & Especificações Técnicas

Guia rápido de design system para o Web Designer / Programador Frontend implementar a marca em canais digitais.

Aviso ao Web Designer: As cores e fontes especificadas abaixo estão prontas para inclusão via CSS. Recomenda-se o uso de layouts assimétricos com colagens em scrapbook e bastante espaço em branco para manter a atmosfera de revista editorial proposta.

CSS Custom Properties (Variáveis CSS)

Copie e cole a estrutura abaixo diretamente em seu arquivo CSS global (ex: `variables.css` ou `:root`):

:root {
  /* Paleta de Cores Oficiais */
  --color-azul: #2E2A6E;       /* Títulos principais, menus importantes, blocos de fundo */
  --color-laranja: #E8763A;    /* Botões ativos, links importantes, detalhes de grifo */
  --color-creme: #E8C4B8;      /* Cor de suporte de blocos, bordas secundárias */
  --color-off-white: #F4EDE4;  /* Cor de fundo principal das páginas, reduz fadiga visual */
  --color-cinza: #9B9EA6;      /* Textos secundários, bordas gerais, ícones inativos */

  /* Tipografia */
  --font-highlight: 'Cosmodrome Monoline', cursive;
  --font-body: 'Albert Sans', sans-serif;
  
  /* Transições Web Padrão */
  --transition-smooth: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
  --transition-fast: all 0.15s ease-in-out;

  /* Sombra editorial sutil */
  --shadow-sm: 0 2px 8px rgba(46, 42, 110, 0.05);
  --shadow-md: 0 8px 24px rgba(46, 42, 110, 0.08);
}

Declaração de @font-face

Para usar os arquivos de fontes originais da identidade localmente no site, adicione o seguinte bloco ao topo de suas folhas de estilo:

@font-face {
  font-family: 'Cosmodrome Monoline';
  src: url('assets/fonts/Cosmodrome-Monoline.otf') format('opentype');
  font-weight: normal;
  font-style: normal;
}

@font-face {
  font-family: 'Albert Sans';
  src: url('assets/fonts/AlbertSans-Regular.ttf') format('truetype');
  font-weight: 400;
  font-style: normal;
}

@font-face {
  font-family: 'Albert Sans';
  src: url('assets/fonts/AlbertSans-Bold.ttf') format('truetype');
  font-weight: 700;
  font-style: normal;
}

@font-face {
  font-family: 'Albert Sans';
  src: url('assets/fonts/AlbertSans-Italic.ttf') format('truetype');
  font-weight: 400;
  font-style: italic;
}

Regras de Hierarquia Tipográfica Sugerida

Tag / Elemento Família Tipográfica Estilo Sugerido Uso Recomendado em Web
Títulos de Destaque / Citações Cosmodrome Monoline Size: 42px - 56px, Line-height: 1.1 Intervenções manuscritas flutuantes, notas e aspas.
Títulos Principais (h1, h2) Albert Sans (Bold) Size: 32px - 40px, Line-height: 1.2 Títulos principais de seção, caixa alta opcional.
Subtítulos (h3) Albert Sans (Medium/Bold) Size: 20px - 24px, Line-height: 1.3 Títulos de blocos de conteúdo ou cards.
Corpo de Texto (p, span) Albert Sans (Regular) Size: 15px - 16px, Line-height: 1.6 Parágrafos de texto corrido. Altura de linha de 1.6 é essencial.
Botões e Links (a, button) Albert Sans (Bold) Size: 14px - 16px, Color: Laranja / Azul Textos curtos de ação, hover suave, transição de 150ms.
